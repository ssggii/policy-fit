# 페르소나-정책 매트릭스

> **최종 결정은 PRD 6장·ADR-0002가 원본이며, 본 문서는 결정 이전의 분석 스냅샷이다.** 결정 근거 자료 — ADR-0002로 흡수 후 정리 가능. 본문 수치와 PRD·ADR이 다르면 PRD·ADR이 이긴다.
> 목적: MVP 정책 범위 결정 (PRD 6장 A1 이슈)
> 기준: 2026-07-14 웹 검색으로 확인한 요건. 중위소득 수치는 근사(1인 가구 월 약 251만 가정) — **판정 경계가 좁아져 정확 수치 검증이 필수가 됨 (본문 2-1 참조)**.
> ⓑ(수요 적합) 열은 자격질문 코퍼스(143건) 대조 필요 — 작성자 기입.
> v1 대비 변경: 페르소나 소득 250~300만 → **200~250만**. ⓓ 평가를 구간 양 끝값(200만/250만)에서 수행.

## 2. 핵심 발견 (v2)

### 2-1. 페르소나가 '경계 위의 사용자'로 이동 — 제품 설계의 중심 문제가 바뀜
v1(월 275만)에서는 청년월세·주거급여가 여유 있게 '부적합'으로 완결됐다. v2(200~250만)에서는 **두 정책의 판정 경계가 구간 안을 통과**한다(약 215만, 232만 지점). 함의 세 가지:
1. **오판율 리스크가 이 소득 대역에 집중된다** — 골든셋은 이 경계 대역(±20만)을 과표집(oversample)해야 한다.
2. **소득 입력의 정밀도가 판정 품질을 결정한다** — "월 200~250 사이"라는 '대략' 입력으로는 청년월세 판정이 불확실 범위에 걸린다. Story 1-1의 '대략' 허용 설계가 바로 이 지점에서 '추가 확인 필요' 상태와 연동되어야 한다.
3. **공제 로직(30% 공제, 청년 60만+30% 공제)이 원자 평가기의 일부**다 — 총급여를 그대로 임계와 비교하면 경계 대역 전체가 오판된다. DOMAIN.md 소득 원자에 공제 로직 명세 필수.

### 2-2. 시나리오 C(저소득 변형)가 불필요해짐
v1에서 제안했던 별도 저소득 시나리오의 역할을 새 소득 구간의 하단(200만)이 대신한다. 표준 시나리오 하나로 면제군 결정을 가를 수 있게 됨.

### 2-3. 면제군 결정이 표준 시나리오에서 살아남 — ⓓ가 1a를 탈락시킴
소득 200만 지점에서 1a(한정)는 '자가판정 불가'(행정재량 ④가 유일한 면제 경로), 1b(해제)는 완결 도달. **ⓓ 기준이 표준 시나리오만으로 한정/해제를 판별**하게 됐다. 잠정 권고: **해제(1b)** — 단, 원가구 소득·재산은 '모름' 허용 + '추가 확인 필요' 처리.

### 2-4. "시군구청장 인정" — 행정재량 값 유형 (v1과 동일, 중요도 상승)
v2에서는 이 재량이 표준 시나리오의 실제 판정을 막는 것으로 확인됨. DOMAIN.md 원자 값 유형에 '행정재량' 분류 추가 필요: 자가입력 불가 + 선발절차 아님 → '자가판정 불가'의 정당한 트리거.

### 2-5. 주거급여 분리지급의 유관성 상승
v1에서는 소득 초과로 즉시 부적합이었으나, v2 하단에서는 본인 소득이 충족되어 **부모수급여부가 지배 게이트**로 부상. 페르소나에게 실제로 의미 있는 정책이 됐다. 단 신규 원자 2개(부모수급여부, 소득인정액 파생 계산)의 ⓒ 비용은 그대로 — 코퍼스 등장 빈도(ⓑ)가 포함 여부를 갈라야 함.

### 2-6. 후보 지형 변동 (v1과 동일)
중기청 통합 소멸, 도약계좌 신규 종료 → 미래적금 대체. 정책 존속 확인 단계를 정규화 파이프라인에 추가할 근거.

### 2-7. 매입임대·청년수당 (v1과 동일)
매입임대: 요건의 공고 단위 변동이 진짜 문제(ⓐ 전제 각주로 명문화). 청년수당: 새 원칙 하에서 제외 근거 재작성 필요.
